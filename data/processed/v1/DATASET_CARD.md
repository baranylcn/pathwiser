## What an example is

Given a conversation, the current user message, a workflow node and a set of candidate conditions (natural-language descriptions), pick the matching condition or none (`no_match`).

| field | meaning | model input |
|---|---|---|
| `context[]` | last turns before the message `{role, content}` | yes |
| `current_message` | latest user message | yes |
| `node` | workflow node `{name, description}` (+ `origin`) | yes |
| `candidates[]` | `{cid, description}`; cid is positional and meaningless | yes |
| `gold_cid / label_type` | target: a cid, or null for `no_match` | target |
| `candidate_meta[]` | condition uid, family, equivalence group, role, negative strategy, description variant/origin/reviewed | no |
| `construction` | kind (route / other_family / sibling_removed / oos), label_risk, removed gold, pairing | no |
| `slices[]` | evaluation tags: tier, dataset, cond:seen|unseen, svc:seen|unseen, ctx:*, k:*, nm_kind:*, desc:*, risk:* | no |
| `source / split_group_id` | provenance and leakage unit | no |
| `features` | message length, context length, first-turn flag | no |

## Known limitations

- Condition descriptions for Banking77, CLINC150, HWU64, STAR and ABCD are drafts written by an LLM for this project (`reviewed: false` in `data/curated/*.json`). Only SGD / SGD-X descriptions come from the source. Review them before trusting results.
- Banking77 / CLINC150 / HWU64 examples are single-turn with an EMPTY context (`context_origin: none`); no context is fabricated. Context-awareness can only be learned and measured on SGD, STAR and ABCD.
- SGD moments are turns where `active_intent` changes. The user message at such a turn may only imply the intent (e.g. 'Yes, go ahead.'); annotation noise has not been measured.
- `no_match` examples are constructed, not observed (except CLINC out-of-scope). `sibling_removed` examples can contain a partially valid sibling and are flagged `risk:sibling_partial_validity`; they have not been audited by hand.
- STAR: the wizard's `select_task` can precede the user's explicit request; low-information messages are filtered but timing noise remains. Turns followed by several different selected tasks (`multi_gold_turn`, a large share, see Discarded records) are dropped rather than guessed. Single-task STAR dialogues have no explicit routing event and are unused.
- Natural no_match is rare: CLINC out-of-scope is the only observed one. Its candidates are chosen by lexical similarity, so they are often not semantically close to the message.
- ABCD: the moment is the first substantive customer turn (heuristic); flow-level labels only (10 flows).
- Hard negatives use lexical (TF-IDF) similarity plus family structure, not semantic embeddings.
- `requires_context` is NOT computed. Only proxies exist (`ctx:*`, `msg:short` slices). Measure it with a context ablation.
- Held-out families (unseen conditions) were chosen by hand in the config; Banking77 families were authored for this project.
- HWU64 uses 63 labels: the 4 rare labels of the 68 raw ones and the catch-all `general_quirky` are excluded.
- STAR, HWU64 and the Banking77 validation split are deterministic hash splits, not official splits.
- Not yet included: the hand-written gold test set (T5), LLM-generated non-intent conditions (T4), `ambiguous` labels, multilingual data.
- SGD is CC BY-SA 4.0 (share-alike): derived data inherits that obligation. STAR/ABCD licenses shown are repository licenses.
